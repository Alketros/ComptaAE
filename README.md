# Compta AE

Comptabilité simple pour auto-entrepreneur, à utiliser sur iPhone :
livre des recettes, registre des achats (avec lecture automatique des factures PDF et des photos de tickets),
tableau de bord URSSAF, exports PDF / Excel / dossier complet pour un contrôle.

**Ouvrir l'app : https://alketros.github.io/ComptaAE/**

## Installation sur l'iPhone (une seule fois)

1. Ouvrez le lien ci-dessus dans **Safari**.
2. Touchez le bouton **Partager** (carré avec une flèche), puis **« Sur l'écran d'accueil »**.
3. Utilisez ensuite toujours l'icône **Compta AE** de l'écran d'accueil.

C'est tout : pas d'App Store, pas de compte, pas d'expiration. L'app fonctionne aussi sans connexion.

## Vos données

- Elles restent **uniquement dans votre iPhone** (rien n'est envoyé sur internet, ni dans ce dépôt GitHub).
- Une fois par mois : onglet **Export → Créer une sauvegarde → Enregistrer dans Fichiers → iCloud Drive**.
  Si vous changez de téléphone ou supprimez l'icône, il suffit de restaurer cette sauvegarde.

## Contenu du dépôt

- `docs/` : l'application (publiée par GitHub Pages).
- `archive-ios-natif/` : ancienne version Swift (non utilisée, nécessite un Mac).
